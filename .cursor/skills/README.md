## Project skills

Put project-scoped Cursor skills in subfolders under this directory.

### Structure

Each skill lives in its own folder and must include `SKILL.md`:

```text
.cursor/skills/<skill-name>/
└── SKILL.md
```

Optional supporting files:

```text
.cursor/skills/<skill-name>/
├── SKILL.md
├── reference.md
├── examples.md
└── scripts/
```

### Template

Copy `.cursor/skills/skill-template/` to start a new skill.
