# Skill template

## When to use

Use this folder as a starting point when creating a new project skill.

## Instructions

- Replace `name` and `description` in the YAML frontmatter.
- Rename the folder to your skill name (lowercase, hyphens).
- Keep this file concise; move long details into `reference.md` if needed.

## Examples

Example trigger phrases to include in your `description`:

- "Use when the user mentions <your keyword>"
- "Use when working with <your domain> files"
